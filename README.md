# UI/UX Portfolio Learning Project

## Purpose

A UI/UX portfolio website inspired by the provided reference image, built as a hands-on learning project.

## Stack and learning context

- Vanilla HTML, CSS, and minimal JavaScript
- Some existing HTML/CSS experience
- Learning Flexbox, Grid, responsive CSS, and animations
- C# experience; beginner JavaScript experience

## Design requirements

- Dark portfolio layout
- Desktop layout with independently scrolling sidebar and projects columns using CSS
- Responsive mobile layout

## Ponytail full constraints

- Keep dependencies minimal
- Prefer native CSS and browser features first
- Avoid unnecessary abstractions
- Favor simple, readable implementations

## Learning workflow

- Explain concepts before edits
- Work one step at a time
- Get approval before making changes when practical

## Roadmap

1. Define the semantic HTML structure
2. Add the dark desktop layout with CSS
3. Add project content and visual styling
4. Add responsive mobile behavior
5. Add small, purposeful animations
6. Add minimal JavaScript only where native HTML/CSS is insufficient
7. Review accessibility, polish, and browser behavior

## Current status

Starter files have been inspected. No semantic structure edit has been approved yet.
